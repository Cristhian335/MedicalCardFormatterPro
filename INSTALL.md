# Medical Card Formatter Pro

# INSTALL.md

## Guía de instalación


---

# 1. Requisitos del sistema


Medical Card Formatter Pro es un complemento nativo para Anki.


Requisitos:


- Anki 25.09 o superior.
- Windows, macOS o Linux.


No requiere:

- aplicaciones externas.
- servidores.
- conexión permanente a internet.



---

# 2. Instalación mediante archivo .ankiaddon


Formato recomendado:


MedicalCardFormatterPro_vX.X.X.ankiaddon



Pasos:


1. Abrir Anki.


2. Ir a:


Herramientas

↓

Complementos



3. Seleccionar:


Instalar desde archivo



4. Elegir el archivo:


MedicalCardFormatterPro_vX.X.X.ankiaddon



5. Reiniciar Anki.



Después del reinicio el complemento estará instalado.



---

# 3. Instalación manual mediante ZIP


Si se recibe:


MedicalCardFormatterPro_vX.X.X.zip



Pasos:


1. Extraer el archivo ZIP.


2. Copiar la carpeta:


MedicalCardFormatterPro



Dentro de la carpeta de complementos de Anki.



Ubicación:


Windows:


%APPDATA%\Anki2\addons21



macOS:


~/Library/Application Support/Anki2/addons21



Linux:


~/.local/share/Anki2/addons21



3. Reiniciar Anki.



---

# 4. Primera ejecución


Al iniciar por primera vez:


El complemento debe:


- crear configuración inicial.
- comprobar versión de Anki.
- verificar compatibilidad.


No debe modificar tarjetas automáticamente.



---

# 5. Verificación


Para comprobar instalación:


Abrir Anki.


Ir a:


Herramientas


Debe aparecer:


Medical Card Formatter Pro



La primera pantalla debe mostrar:


✓ Complemento activo

✓ Versión instalada

✓ Estado de compatibilidad
