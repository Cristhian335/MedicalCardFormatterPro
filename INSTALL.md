# Medical Card Formatter Pro

# INSTALL.md

## Guía de instalación


---

# 1. Requisitos del sistema


Medical Card Formatter Pro es un complemento nativo para Anki.


Requisitos:


- Anki 25.09 o superior.
- Windows, macOS o Linux.


No requiere:

- aplicaciones externas.
- servidores.
- conexión permanente a internet.



---

# 2. Instalación mediante archivo .ankiaddon


Formato recomendado:


MedicalCardFormatterPro_vX.X.X.ankiaddon



Pasos:


1. Abrir Anki.


2. Ir a:


Herramientas

↓

Complementos



3. Seleccionar:


Instalar desde archivo



4. Elegir el archivo:


MedicalCardFormatterPro_vX.X.X.ankiaddon



5. Reiniciar Anki.



Después del reinicio el complemento estará instalado.



---

# 3. Instalación manual mediante ZIP


Si se recibe:


MedicalCardFormatterPro_vX.X.X.zip



Pasos:


1. Extraer el archivo ZIP.


2. Copiar la carpeta:


MedicalCardFormatterPro



Dentro de la carpeta de complementos de Anki.



Ubicación:


Windows:


%APPDATA%\Anki2\addons21



macOS:


~/Library/Application Support/Anki2/addons21



Linux:


~/.local/share/Anki2/addons21



3. Reiniciar Anki.



---

# 4. Primera ejecución


Al iniciar por primera vez:


El complemento debe:


- crear configuración inicial.
- comprobar versión de Anki.
- verificar compatibilidad.


No debe modificar tarjetas automáticamente.



---

# 5. Verificación


Para comprobar instalación:


Abrir Anki.


Ir a:


Herramientas


Debe aparecer:


Medical Card Formatter Pro



La primera pantalla debe mostrar:


✓ Complemento activo

✓ Versión instalada

✓ Estado de compatibilidad
---

# 6. Actualización del complemento


Antes de actualizar:


1. Sincronizar Anki.


2. Crear copia de seguridad de la colección.


3. Instalar la nueva versión.



La actualización debe conservar:


- configuración del usuario.
- preferencias.
- historial.
- compatibilidad con la colección.



No debe modificar:


- tarjetas existentes.
- plantillas.
- tipos de nota.
- programación de repasos.



---

# 7. Desinstalación


Para eliminar el complemento:


Abrir Anki.


Ir a:


Herramientas

↓

Complementos



Seleccionar:


Medical Card Formatter Pro



Pulsar:


Eliminar



Reiniciar Anki.



La desinstalación no debe dejar cambios permanentes en la colección.



---

# 8. Solución de problemas


## El complemento no aparece


Comprobar:


- Que Anki esté actualizado.
- Que el archivo esté instalado correctamente.
- Que Anki haya sido reiniciado.



---

## Anki muestra un error


Realizar:


1. Copiar mensaje de error.


2. Guardar información de versión.


3. Revisar archivo de registro.



Información necesaria:


- Versión de Anki.
- Sistema operativo.
- Versión del complemento.
- Descripción del problema.



---

# 9. Compatibilidad con otros complementos


Medical Card Formatter Pro debe coexistir con otros add-ons.


Si existe conflicto:


- informar al usuario.
- registrar el error.
- evitar bloquear Anki.



No debe modificar funciones externas.



---

# 10. Prueba inicial recomendada


Antes de utilizarlo en toda la colección:


Realizar prueba con:


- 5 tarjetas.
- Una tarjeta con imagen.
- Una tarjeta con fórmulas.
- Una tarjeta con tablas.
- Una tarjeta con múltiples opciones.



Comprobar:


✓ Formato correcto.

✓ Contenido intacto.

✓ Sin pérdida de información.

✓ Backup funcional.
